# 🛒 Shopping Cart Management System

## 📌 Project Description

The Shopping Cart Management System is a menu-driven Python application that simulates a simple online shopping experience.

Users can view products, search for products, add items to their cart, update quantities, remove products, calculate bills, apply discounts, and save previous bills.

This project demonstrates practical implementation of Python concepts learned during the 6-week internship.

## 🎯 Project Objectives

- Develop a real-world Python application.
- Understand shopping cart operations.
- Implement Object-Oriented Programming.
- Practice Python data structures.
- Perform file handling and exception handling.

## ✨ Features

- View available products.
- Search products by name or category.
- Add products to shopping cart.
- Update product quantities.
- Remove products from cart.
- Check product stock availability.
- Calculate total shopping amount.
- Apply percentage and fixed discounts.
- Generate unique order IDs.
- Generate and save shopping bills.
- View previous shopping bills.
- Handle invalid inputs and errors.
